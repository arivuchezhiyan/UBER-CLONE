## 🚀 Getting Started (Quick Steps)

### 1. Install Dependencies (2 min)
```bash
npm run install:all
```

### 2. Start MongoDB
```bash
mongod
```

### 3. Run Backend (Terminal 1)
```bash
cd server && npm run dev
```

### 4. Run Frontend (Terminal 2)
```bash
cd client && npm start
```

### 5. Open App
```
http://localhost:3000
```
